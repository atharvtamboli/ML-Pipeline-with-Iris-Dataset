# ML-Pipeline-with-Iris-Dataset

This project demonstrates a Scikit-learn ML Pipeline using:

- SimpleImputer
- StandardScaler
- RandomForestClassifier

## Pipeline

Iris Dataset
→ Missing Value Imputation
→ Standard Scaling
→ Random Forest Classification
→ Evaluation

## How to Run

Install dependencies:

pip install -r requirements.txt

Run:

python task17_pipeline.py
